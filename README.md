# RustPractice

My personal Rust learning repository. Started from zero, learning Rust
to eventually build a CLI tool combining log analysis, password
strength checking, and a simple port scanner.

## Structure

- `array/`, `function/`, `Loop/`, `IF-Condition/` — early self-study on
  basic control flow and data types
- `Assignment/` — exercises from a structured learning plan, one crate
  per topic
- `playground-test/` — scratch space for quick experiments

## Progress

- [x] Variables & mutability (`let`, `mut`, scalar types)
- [x] Ownership (move, `Copy`, `.clone()`)
- [x] References & borrowing (`&`, `&mut`, borrow checker rules)
- [x] Slices (`&str`, `&[T]`)
- [x] Structs & `impl` (methods, `#[derive(Debug)]`)
- [x] `Option` / `Result` and error handling with `match`
- [x] Enums (`enum`, `match`, `if let`)
- [ ] `Vec<T>` and iterators
- [ ] More to come...
